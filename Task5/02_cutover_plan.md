
# Cutover план

| Этап | Описание действия | Ключевые задачи | Ответственные | Сроки | Риски и меры |
|------|-----------------|----------------|---------------|-------|-------------|
| Подготовка | Подготовка инфраструктуры | Развернуть окружение, настроить CI/CD | DevOps | 2 недели | Недостаток ресурсов → capacity planning |
| Подготовка данных | Инвентаризация данных | Очистка, дедупликация | Data Eng | 2-3 недели | Плохое качество → правила валидации |
| Разработка | Реализация сервисов | API, DB, интеграции | Backend | 4-6 недель | Ошибки → code review |
| Тестирование | Нагрузочное тестирование | Проверка SLA | QA | 2 недели | Нагрузка → tuning |
| Parallel Run | Запуск двух систем | Синхронизация данных | DevOps + Backend | 2-4 недели | рассинхрон → reconciliation |
| Постепенный cutover | Перевод пользователей | Feature flags | Product | 1-2 недели | ошибки → rollback |
| Завершение | Отключение старой системы | Архивация | DevOps | 1 неделя | потеря данных → backup |
