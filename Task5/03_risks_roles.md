
# Риски и меры

## Основные риски

### 1. Рассинхронизация данных
- решение: dual-write + reconciliation

### 2. Перегрузка инфраструктуры
- решение: масштабирование + мониторинг

### 3. Ошибки интеграций
- решение: retry + fallback

### 4. Человеческий фактор
- обучение пользователей

## Роли

- Архитектор — стратегия
- DevOps — инфраструктура
- Backend — сервисы
- QA — тестирование
- Data Engineer — миграция данных
- Product — управление переходом
