# Модель тегирования данных

## 1. Цель

Обеспечить автоматическое управление доступом и защитой данных

---

## 2. Теги

| Тег | Описание |
|-----|--------|
| PII | персональные данные |
| MEDICAL | медицинские |
| FINANCE | финансовые |
| INTERNAL | внутренние |
| PUBLIC | публичные |

---

## 3. Пример

```json
{
  "field": "diagnosis",
  "tags": ["MEDICAL", "HIGH_SENSITIVE"]
}
```

## 4. Использование
	•	ABAC
	•	masking
	•	audit
	•	API filtering

## 5. Вывод

Tagging — ключевой механизм управления безопасностью
