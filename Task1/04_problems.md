# Проблемные зоны

## 🔴 Критические

1. Хранение данных в Excel
2. Общий файловый диск
3. Отсутствие разграничения доступа
4. Отсутствие аудита
5. Передача данных через email
6. Отсутствие шифрования

---

## 🟠 Средние

- отсутствие API безопасности
- отсутствие централизованной модели данных
- отсутствие мониторинга

---

## 🟡 Организационные

- ручные процессы
- отсутствие политики безопасности
- отсутствие data governance

---

## 2. Root cause

- отсутствие архитектуры данных
- отсутствие security модели
- использование файлов как системы хранения

---

## 3. Вывод

Проблемы носят системный характер  
Требуется:
- изменение архитектуры
- внедрение политики работы с данными
