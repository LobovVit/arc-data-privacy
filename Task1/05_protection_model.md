# Модель защиты данных

## 1. Подход

Используются принципы:
- Zero Trust
- Defense in Depth
- Privacy by Design

---

## 2. Методы защиты

### Encryption
- TLS (in transit)
- AES-256 (at rest)

### Masking
- скрытие данных в UI

### Tokenization
- замена чувствительных данных

### Anonymization
- для BI / ML

---

## 3. Применение

| Тип данных | Метод |
|------------|------|
| MEDICAL | шифрование + строгий доступ |
| PII | шифрование + masking |
| FINANCE | шифрование + изоляция |

---

## 4. Дополнительно

- KMS (управление ключами)
- audit logging
- SIEM

---

## 5. Вывод

Модель защиты должна быть встроена в архитектуру, а не добавлена позже
